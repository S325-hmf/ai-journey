## 二、一个一个装

### 1. Git（约 60 MB）

1. 打开 https://git-scm.com/download/win ，等 2 秒，页面会自动开始下载；
   没反应就点页面中间的 **「Click here to download manually」**。
2. 双击 `Git-2.xx.x-64-bit.exe`。
3. 安装向导**一路点 Next**，什么都不用改（默认选项就是对的），最后点 Install。
4. 装完点 Finish。

### 2. Python 3.12（约 25 MB）⭐ 这一步有个坑

1. 打开上面的直链，下载 `python-3.12.10-amd64.exe`。
2. 双击运行，**先别点 Install Now**：
   把窗口最下面的 **☑ Add python.exe to PATH** 勾上（默认是不勾的！）。
3. 再点 **Install Now**，等进度条走完。
4. 结束时如果有 **「Disable path length limit」**，点它（可选，点了更省事）。
5. Close。

> 忘了勾 PATH 的后果：装完在终端输 `python` 还是弹微软商店。补救办法是重新运行安装包 → Modify → 勾上 PATH，或者直接重装一遍。

### 3. VS Code（约 100 MB）

1. 打开 https://code.visualstudio.com/download ，点 **Windows** 那一列的 **User Installer**（蓝色按钮，64-bit）。
2. 双击安装，同意协议 → Next。
3. 「选择附加任务」这一步，确认勾上：
   - ☑ 将「通过 Code 打开」操作添加到 Windows 资源管理器文件上下文菜单
   - ☑ **添加到 PATH**（默认已勾，别取消）
4. Next → Install → Finish。

## 三、关掉微软商店的 python 占位符（关键）

你机器上 `python` 现在指向商店占位符，不关掉它，装了真 Python 也会被抢走。

1. `Win + I` 打开设置
2. 应用 → 高级应用设置 → **应用执行别名**
3. 找到这两个，把开关**关掉**：
   - `python.exe`（应用安装程序）
   - `python3.exe`（应用安装程序）

## 四、验证（必须新开终端）

**把所有终端窗口关掉**，然后 `Win + X` → 终端（或 PowerShell）。

逐条粘贴，每条回车：

```powershell
git --version
```

```powershell
python --version
```

```powershell
code --version
```

预期：

```
git version 2.5x.x.windows.1
Python 3.12.10
1.1xx.x
<hash>
```

**三条都有输出 = 第 0 周第 1 项基本过关。** 然后做第五节的 uv。

## 九、报错对照表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 输 `python` 弹出微软商店 | ①PATH 没勾 ②别名没关 | 先做第三节；再不行重装勾 PATH |
| `'git' 不是内部或外部命令` | 没开新终端 | 关掉全部终端窗口重开 |
| `'code' 不是内部或外部命令` | 安装时没勾 PATH | 重装 VS Code 勾「添加到 PATH」 |
| `uv` 找不到 | 路径没进 PATH | 重开终端；手动加 `%USERPROFILE%\.local\bin` |
| 显示 `Python was not found` | 还是商店占位 | 第三节别名没关干净 |
| 中文乱码 | 终端编码 | `chcp 65001` |
| 安装包被「已阻止」 | SmartScreen | 点「更多信息」→「仍要运行」 |
