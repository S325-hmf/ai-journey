## 卡点

**VS Code 提交一直转圈**（21:03 起卡死两个 git 进程）。

诊断结果：

| 目标 | 连通性 |
|---|---|
| `github.com:443` | ❌ 连接超时 / 被重置 |
| `ssh.github.com:443` | ✅ |
| `api.github.com:443` | ✅ |

结论：网络只切断了 `github.com` 这一个 HTTPS 入口，不是 Git 操作错误。

解决：生成 ed25519 密钥 → 加到 GitHub → `~/.ssh/config` 指向 `ssh.github.com:443` → 远程地址改为 `git@github.com:S325-hmf/ai-journey.git`。已生效。

顺带写入的容错配置：

```
http.lowSpeedLimit 1000
http.lowSpeedTime 20
http.postBuffer 524288000
http.version HTTP/1.1
```
